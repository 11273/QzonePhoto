常见问题

下载前，你可能想先确认这些。

这是官网吗？

是。请认准 qzonephoto.getgit.one；不需要加群，也不用注册官网账号。

不知道选哪个版本怎么办？

官网会优先识别当前电脑。Windows 大多数用户选择 64 位；Mac 可在“关于本机”查看是 Apple 芯片还是 Intel。

Mac 第一次打不开怎么办？

请先确认安装包来自本官网。把应用拖到“应用程序”后，如 macOS 提示无法验证开发者，可在“系统设置 → 隐私与安全性”中选择“仍要打开”；也可以按住 Control 点按应用，再选择“打开”。不需要在终端输入命令。

下载没有开始怎么办？

点击首屏的“选择其他系统或版本”重新选择，或 查看历史版本与其他下载方式。仍无法下载时，可以提交反馈。

想先留下一份，再慢慢整理吗？

官网会优先推荐适合当前电脑的版本，也可以自己选择。
